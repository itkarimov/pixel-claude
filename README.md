# Pixel Claude

Голосовая пиксельная оболочка над `claude` CLI. Вертикальное окно: сверху 60 % —
портрет персонажа с эмоциями, снизу 40 % — лента сессии (что сказали, что делаю,
что ответила). Говоришь в микрофон — она слышит, работает и отвечает голосом.

## Запуск

Ярлык **Pixel Claude** на рабочем столе. Или:

```bash
python app.py
```

Крестик не закрывает окно, а прячет его в трей — процесс `claude` продолжает
держать сессию, микрофон работает. Клик по значку в трее возвращает окно, там же
в меню правой кнопкой — включение микрофона и настоящий выход.

## Как это работает

```
микрофон → энергетический VAD → faster-whisper (ru)
        → claude -p --output-format stream-json --resume <session>
        → лента + эмоция портрета + edge-tts → динамики
```

- Каждая реплика — отдельный процесс `claude -p`, контекст держится через
  `--resume <session_id>`, поэтому сессия не рвётся. Проверено: `--resume` не
  плодит новые id — один файл живёт весь разговор.
- В системный промпт дописано требование отвечать одной-двумя фразами и ставить
  тег эмоции: `[done] Готово, поправила три файла.` Тег снимается перед показом
  и озвучкой, портрет переключается на нужный спрайт.
- Пока играет голос, микрофон заглушён — иначе оболочка слышит саму себя.

## Скорость

Первая версия поднимала новый процесс `claude` на каждую реплику. Замеры одного
хода показали, где уходило время:

```
 0.0 →  4.8 с   хуки
 4.8 →  8.0 с   инициализация CLI
 8.0 → 10.6 с   ответ модели        ← всего 2.6 с полезной работы
10.6 → 13.5 с   финализация
13.5 → 15.6 с   завершение процесса
```

Тринадцать секунд накладных на две с половиной секунды дела, а с подключёнными
MCP-серверами первый ход раздувался до **35 секунд**. Что сделано:

1. **Один долгоживущий процесс** (`--input-format stream-json`) вместо процесса
   на реплику — хуки и инициализация отрабатывают один раз.
2. **MCP-серверы отключены** (`--strict-mcp-config`): оболочке они не нужны,
   а грузятся долго. Выключается флагом `disable_mcp` в `config.json`.
3. **Процесс поднимается при старте окна**, пока человек тянется к микрофону.
4. **Озвучка по приходу текста**, а не по финальному событию — минус ещё ~3 с.
   Побочный плюс: промежуточное «сейчас посмотрю» звучит естественно.

Стало: вопрос → голос за **5–6 секунд** (из них ~1.7 с — синтез речи), первый
ход около 8. Смена модели не помогает — проверено, opus, sonnet и haiku дают
одинаковое время, потому что упирается не в модель.

Реплика, сказанная до конца хода, не отбрасывается, а придерживается в очереди:
голос звучит раньше, чем ход закрыт, и человек успевает заговорить снова.

## Сессии

Выпадающий список над лентой — **тот же, что в сайдбаре приложения Claude**, с
теми же названиями: «Крипта», «Instagram carousel», «БОТ персональный ДДС».
Сессии всех проектов сразу, свежие сверху, рядом с названием — папка проекта.
Выбрали — оболочка продолжает эту сессию (`--resume`), **переключает рабочую
папку** на её `cwd` и подтягивает в ленту последние реплики, чтобы не начинать с
пустого экрана. Кнопка `+` начинает новую в папке из `config.json`.

Последняя сессия запоминается в `state.json` рядом с `config.json`, поэтому при
следующем запуске окно продолжает с того же места. Файл локальный, в гите его нет.

### Откуда берутся названия

Приложение держит свой реестр сессий в IndexedDB (`%APPDATA%\Claude`), и лезть
туда из питона было бы больно. Но заголовок, заданный в приложении, оно
дублирует записью `custom-title` прямо в файл CLI-сессии — оттуда и читаем,
с конца файла, наращивая окно поиска.

```
~/.claude/projects/<путь проекта с дефисами>/<session_id>.jsonl
```

Путь кодируется заменой **любого** не-буквенно-цифрового символа на дефис,
включая точки и подчёркивания:
`C:\UniTap\unitap_wibe_code` → `C--UniTap-unitap-wibe-code`.

Безымянные сессии (прогоны CLI, фоновые агенты claude-mem) в приложении не
показываются — в списке их тоже нет. Если нужны, есть
`sessions.list_sessions(unnamed=True)`.

### Сессии, заведённые здесь, в приложении не появятся

Приложение ведёт сайдбар по своей базе с собственными идентификаторами вида
`local_af3ad0db-…` — среди 589 файлов CLI-сессий таких нет вовсе. То есть у него
свой реестр, а в файлы сессий оно только проставляет заголовок. Зарегистрировать
там сессию снаружи нечем, и лезть в чужую IndexedDB — плохая идея.

Поэтому оболочка ведёт свой реестр `mine.json`: сессия, начатая здесь,
запоминается с заголовком по первой фразе и показывается в списке с меткой `▸`.
В приложении Claude она не появится — это ограничение, а не поломка.

## Файлы

| Путь | Что делает |
|------|-----------|
| `app.py` | точка входа, связывает всё вместе |
| `core/agent.py` | запуск claude CLI, разбор stream-json, эмоции, описания инструментов |
| `core/sessions.py` | список сессий проекта и подгрузка их хвоста в ленту |
| `core/stt.py` | микрофон, VAD, faster-whisper |
| `core/tts.py` | edge-tts → ffmpeg → звук, запасной SAPI без интернета |
| `ui/window.py` | окно, портрет, моргание, кнопка микрофона, лента |
| `tools/slice_ref.py` | нарезка листа эмоций `assets/ref.png` на спрайты |
| `tools/gen_character.py` | старый генератор арта кодом (спрайты лежат в `assets/sprites_generated/`) |
| `tools/smoke_test.py` | собрать окно и снять скриншот |
| `tools/agent_test.py` | проверить связку с claude без окна |
| `tools/audio_test.py` | микрофоны, синтез речи, кэш модели (`--play` — со звуком) |

## Настройки — `config.json`

| Ключ | Смысл |
|------|-------|
| `workdir` | в какой папке работает claude |
| `model` | пусто = модель по умолчанию |
| `permission_mode` | `acceptEdits` — правки файлов без вопросов, Bash по-прежнему спросит и в headless будет отклонён. `bypassPermissions` снимет все тормоза — на свой риск |
| `voice` | голос edge-tts, по умолчанию `ru-RU-SvetlanaNeural` |
| `whisper_model` | `tiny` / `base` / `small` / `medium` — точность против скорости |
| `vad_start_rms` | порог громкости начала фразы; шумный микрофон — поднять |
| `vad_silence_ms` | сколько молчать, чтобы фраза считалась законченной |
| `portrait_share` | доля высоты под портрет |

## Эмоции

`neutral` `smile` `happy` `laugh` `surprised` `puzzled` `think` `sad` `crying`
`angry` `unhappy` `shy` `love` `tired` `sly` `excited` `relief` `victory` `done`

Портрет нарезан из листа `assets/ref.png` (40 клеток, 8×5). Клетки режутся не по
формальной сетке — она на листе неровная, — а по двум привязкам: центр фигуры по
массе тёмного и верхняя линия волос. Поэтому голова стоит на месте при любой
смене эмоции. Арт на листе нарисован с двукратным апскейлом, спрайты приводятся
к родному разрешению 88×98 — так целочисленное масштабирование окна даёт частый
шаг и портрет заполняет панель.

Все 40 клеток лежат в `assets/sheet/r<ряд>c<колонка>.png`, общий вид —
`assets/preview_grid.png`. Чтобы поменять, какая клетка отвечает за эмоцию,
правьте `MAPPING` в `tools/slice_ref.py` и перенарежьте:

```bash
python tools/slice_ref.py
```

Список эмоций задаётся в `core/agent.py` (`EMOTIONS`) — оттуда он попадает в
промпт. Добавляете спрайт — добавьте имя туда же, иначе тег не распознается.

Моргания нет: на листе нет кадра с закрытыми глазами и нейтральным ртом, а
подставлять чужую позу — заметно. Вместо него портрет чуть покачивается,
имитируя дыхание.

## Если что-то не работает

- **`claude CLI не найден`** — проверь, что `claude` есть в PATH.
- **`401 OAuth access token has expired`** — вылетела авторизация CLI. Открой
  терминал, запусти `claude` и войди заново.
- **Микрофон не слышит** — подними `vad_start_rms`, проверь устройство ввода
  по умолчанию через `python tools/audio_test.py`.
- **Молчит** — `python tools/audio_test.py --play`; если edge-tts не отвечает,
  включится системный голос Windows.
